Adapter formats and native role binding remain unchanged. Desired behavior: a delegated coder returns a bounded issue and supporting evidence to its coordinator; the coordinator resolves recoverable prerequisites within existing authority, routes warranted owner work, and continues independent authorized work. A real missing permission, requirement decision, or unavailable prerequisite still blocks the dependent action. A skill-caused pause names and links the source, quotes the operative instruction, and separates explicit requirements from interpretation. Work that requires a missing decision is not performed merely to make an approval packet concrete.

Information placement: universal question and source-provenance behavior belongs beside the harness decision gate; coder-specific suspension and return rules belong in the existing approval gate; orchestration of returned conditions belongs beside return classification and Stop Conditions, with a short matching handoff reference. Do not repeat the full decision-readiness format in every owner.

A delegated executor cannot widen its batch to perform unrelated work. Unaffected work continues only when its dependencies, authority, and any plan sequencing remain satisfied.

Rejected alternatives: unconditional persistence would weaken permission; every conflict becoming a question would preserve unnecessary pauses; a new routing layer would duplicate the current owners; putting the entire correction only in the harness would leave contradictory local gates in place.
